# Thuy Le — project instructions

## Design
For ANY website, landing page, form, email or visual asset, follow `brand/BRAND.md` and start from `brand/tokens.css`.

- Font: Helvetica Neue (Bold for headlines), with Instrument Sans as the web fallback. No serif fonts. No Inter, Poppins or Montserrat.
- Colours: warm browns and neutrals only (Espresso, Cocoa, Mocha, Latte, Sand, Cream, Linen, Stone).
- Reference implementation: `careers-site/`.

## Hosting
Sites are hosted on Netlify. Ask before publishing or changing a live site.
